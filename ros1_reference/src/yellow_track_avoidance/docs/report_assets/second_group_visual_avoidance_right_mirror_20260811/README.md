## 与第一组图片的差异

- 圆片错列方向相反，使用本轮重新采集的当前实景和坐标；
- 黄线图由“四联过程图”改为“置信度叠加主图+截面曲线+指标卡”；
- 圆片图新增红色分割、白心掩膜、20扇区极坐标和候选筛选漏斗；
- 定位验证由固定500 mm尺度图改为连续54帧散点和时间序列；
- 障碍建模突出完整costmap与4个紧凑语义障碍的职责差异；
- CPU对比由柱状图改为哑铃图；
- 520帧结果由条带统计改为验收矩阵；
- 没有复用第一组“五个关键时刻”横排轨迹版式。
