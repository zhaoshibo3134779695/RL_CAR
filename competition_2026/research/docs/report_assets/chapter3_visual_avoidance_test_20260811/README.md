## 尚缺的真实素材

现有仓库、bag 和保存图片中没有一张能够同时看到以下全部内容的本车外部实拍照片：

- 完整机器人；
- 左右黄色边界；
- 两枚红白反坦克雷；
- 车辆预期行驶方向。

`3.2.4.0` 是真实测试环境的车载相机视角，可以立即使用，但不能替代外部整车照片。建议后续人工补拍时采用斜上方视角，拍摄高度约 1.2～1.6 m，确保整车、双圆片和两侧边界同时进入画面；另拍一张车辆处于两圆片之间或刚完成第一段横移时的照片。不要放置尺子、工具、电脑窗口和其他无关物品。

## 数据边界

- `0.676 m` 来自最新无尺子错列现场帧；`0.500 m` 来自独立尺度标定实验，正文中不得混为同一组数据。
- 五时刻绕障图和规划图来自成功 Stage 1 Trial 7 的实际 rosbag，不是相机连续照片。
- CPU 图和 520 帧统计图来自已有验收报告的真实汇总数字，不包含伪造时间序列。
- 图片标题建议使用 Word 的“插入题注”统一添加，不要直接修改 PNG 内部内容。
