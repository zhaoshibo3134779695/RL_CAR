# 米制 BEV 标定说明

## 当前结果

当前固定相机、640×480 RGB 分辨率和现场光照下，米制地面标定已经完成，配置位于 `config/calibrated.yaml`。车辆运动仍保持关闭。

相机固定光度参数为：自动曝光关闭、曝光 `100`、增益 `0`。相机重启后必须重新核对这三个值；名义曝光 `480` 会让当前灯光下的地面严重过曝。

标定链路：

```text
RGB 棋盘内参
  → 10 帧深度点云地面平面
  → 深度/彩色相机外参
  → 黄线中心距 0.91 m 修正深度比例
  → 两只 0.10 m 圆片复核尺度
  → 米制 BEV
```

## 标定数值

| 指标 | 结果 |
|---|---:|
| RGB 内参重投影 RMS | 0.178 px |
| 地面点云帧数 | 10 |
| 地面平面支持率中位数 | 84.37% |
| 平面内点 P95 距离 | 4.84 mm |
| 深度比例修正 | 1.07865 |
| 修正后彩色相机离地高度 | 0.170 m |
| 黄线中心参考宽度 | 0.910 m |
| 离线回投黄线宽度 | 0.905 m |
| 两只圆片尺度复核 | 0.0962 / 0.0990 m |

BEV 输出为 640×800，映射横向范围 1.01 m，其中黄线中心距为 0.91 m，左右各保留 0.05 m 图像余量。纵向映射范围为 1.569 m：近端截面位于彩色相机地面投影前方 0.312 m，远端位于前方 1.881 m。原图识别仍使用此前验收通过、向图像底部闭合的六点区域；该区域与米制四边形独立，避免标定角点在图外时扩大计算量或裁掉靠边圆片。

BEV 坐标约定：

```text
x：向前，BEV 底部为 0 m
y：向左，BEV 中心为 0 m
```

这里的 `x=0` 是最靠近车辆的有效可视地面截面，不是 `base_link`。
2026-07-24 现场测得右前轮参考点到右侧圆片中心为 `0.47 m`；结合圆片
BEV 坐标和 `0.33 m × 0.30 m` 车体矩形反算后，当前采用保守的
`base_link -> BEV x=0` 前向偏移 `0.39 m`。原始 `center_m` 保持 BEV
局部坐标，ROS 调试 JSON 同时发布修正后的 `center_base_m`。迁移相机或
车辆后必须重新测量该偏移。

- 圆片坐标分别约为 `(0.358 m, -0.275 m)` 和 `(0.497 m, 0.129 m)`；
- 无图像处理错误；
- 两个安全膨胀区同时占据通道时，规划器输出 `no_collision_free_candidate` 并保持 STOP，符合预期；
- `control.enable_motion=false`。

完整机器可读报告：`calibration_runs/current/calibration_report.json`。

## 实时复核

标定接入实时节点后，固定现场连续采集 60 帧：

- 实际输出频率 `10.03 Hz`；
- 单帧处理耗时 P50/P95 为 `89.08 / 97.38 ms`；
- 双黄线 `60/60`、两个圆片 `60/60`；
- 两个圆片前向/横向坐标标准差分别为 `1.38/0.71 mm`、`1.05/0.58 mm`；
- 黄线历史补检、圆片历史补检、运动使能、实时规划均为 `0/60`；
- 所有帧保持 `STOP`，原因均为 `planning_disabled`。

完整连续帧数据：`calibration_runs/current/live_validation.json`。

## 标定失效条件

出现以下任一变化后必须重新标定：

- 相机位置、俯仰、横滚或支架发生移动；
- RGB 分辨率或镜头参数改变；
- 地垫或黄线实际宽度改变；
- 相机离地高度改变；
- 去畸变内参文件被替换。

当前相机发布的 `/camera/color/camera_info` 仍为零内参；节点使用配置文件中已经验收的 RGB 内参完成去畸变，不能改回依赖该零值话题。
